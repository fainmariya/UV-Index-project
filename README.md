# 🌤️ UV Index Project

A small weather dashboard that shows the current UV index for any city.  
Built with **Node.js**, **Express**, and **EJS** templates.

---

## 🧠 Stack
- Node.js  
- Express.js  
- EJS templating  
- Open-Meteo public API  
- HTML5 / CSS3  

---

## 🚀 Features
- Fetches UV index and weather data from Open-Meteo API  
- Renders dynamic EJS templates on the server  
- Displays color-coded UV alerts (low / medium / high risk)  
- Handles invalid city names with user-friendly errors  
- Responsive layout for desktop + mobile  

---
